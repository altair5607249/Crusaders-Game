# UIS to IAS
This is just a lil' anecdote about how hard it was for me to switch from UserInputService (UIS) to InputActionSystem (IAS).

## Getting Accustomed to UIS
As I began developing on Roblox, I always used UIS to map user inputs to in-game actions, though mostly for simple actions such as sprinting and shiftlock.  

However, once I got the bright idea to start working on Crusaders towards the end of May, I took this practice of using UIS to the next level. Not only did map user inputs to sprinting and shiftlock, but I mapped them to everything else! This included the M1s, non-damaging techniques, and character-exclusive bare-style and weapon-style attacks.  

And just when I thought I was making amazing progress... while I was refining my UIS-based code for the character-exclusive attacks, I scrolled through the Roblox Developer Forums for advice and noticed that a lot of developers were switching to IAS. Everyone was calling UIS deprecated, so I investigated why, only to realize how much easier and more scalable IAS is compared to UIS!
