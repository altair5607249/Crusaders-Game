# Expanding the Beta
Right now, the game is alright, but it could use more of everything: custom maps, characters, character balance, and network optimization!  

...Also, I need to document my work better. It's quite hard doing all of this work retroactively.

## Main Idea
It isn't imperative that this game reaches a wider audience, but I would like to make the game better simply for the sake of giving my friends a more dynamic experience.

## Documentation
Moving forward, I definitely need to document my work better if I'm gonna have any chance at properly expanding the game past this open beta phase.  

## Custom Maps
I want to make more custom maps, rather than using public assets. 

It's nice to feature those public assets, and it costs less time, but that doesn't make the game better. What it needs is more original work, and I think I can manage that. I just need to learn how to make proper 3D models, probably with Blender; if I figure that out, I'll probably be able to make custom props as well!

I'm sure Zachary would enjoy making more maps of his own too, since he usually has lots of ideas on his mind regarding this matter, so I'll consult him on this too.

## Characters
The long awaited Orange and Purple are still just concepts; development on them hasn't started yet.  

That's mostly my fault, since I'm not really a master of time management. I'll aim to get their concepts down by the end of November, and hopefully their kits will be done by Christmas!

## Character Balance
The characters are decently balanced at the moment.  

However, that's only because I was able to combine sufficient experimental data from countless playtests with empirical data from the simple Agent-Based Model (ABM) I made.  

If I was able to create an ABM that produces accurate-enough data, then I'd end up with better balance between characters while still saving time on playtesting!

Sounds like a neat idea, but I'd have to learn more about game theory and code that ideal ABM myself, which will take a lot of time. I'm willing to do all that learning and coding since I actually enjoy that stuff, but I can't promise when it will be done.

## Network Optimization
The amount of latency that exists isn't game-breaking, but it's annoying.  

As computer scientists Donald Knuth once wrote in *The Art of Computer Programming* (1974), "Premature optimization is the root of all evil."  

I heartily agree with that statement after seeing some of the stuff I wasted good problem-solving time on, like the listener subsystem in `Sol_Client`.

Therefore, this issue will be one of the last things I address during the general development of this game, kept safe for whenever find myself bored and without real bottlenecks in the future.
