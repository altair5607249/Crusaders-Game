# Documentation
This contains a plethora of written documentation on Crusaders. 

Oh, and thanks for delving this deep into my repo :)

## Contents
Here's a summary of what each subdirectory or file contains, so you don't get lost searching for what you want!
- `cdd/` — Character Design Documents; discusses each character in detail
- `devlog/` — Developer Log; kind of like a diary for developers regarding the thing they're building at the time
- `gallery/` — Gallery; visual archive
- `post-mortems/` — Post Mortems; anecdotes about challenges and bottlenecks I've encountered during development
- `diagrams.md` — Diagrams; graphical explanations of the game's systems and how they flow into/connect with each other
